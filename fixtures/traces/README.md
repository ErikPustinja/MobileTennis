# Sensor traces

Recordings of raw phone sensor samples, used to develop and test gesture
recognition (`packages/sim/src/gesture.ts`).

- `synthetic/` – generated by `node scripts/make-synthetic-traces.mjs`. They
  model a phone held upright like a racket handle with the screen facing the
  player. Only a stand-in until real recordings exist.
- Real recordings go directly into this folder, one file per motion, named
  after the label chosen when recording (e.g. `forehand-jaki.json`).

Format (`SensorTrace` in `packages/protocol/src/trace.ts`):

```json
{
  "format": "mobitenis-trace",
  "version": 1,
  "label": "forehand-jaki",
  "recordedAt": "2026-11-17T12:00:00.000Z",
  "device": "<phone user agent>",
  "samples": [
    { "seq": 0, "t": 1234.5, "accel": [x, y, z], "accelG": [x, y, z], "rot": [a, b, g], "orient": [a, b, g] }
  ]
}
```

`t` is phone time in ms, `accel` and `accelG` are m/s², `rot` is deg/s
(alpha about z, beta about x, gamma about y), `orient` is degrees. A missing
sensor is `null`.
